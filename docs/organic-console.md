# Organic Console

## 问题

普通用户即使有 Agent 想法，也很难独立完成角色定义、知识接入、模型和渠道配置、测试、发布与后续运营。

## 产品方案

通过自然语言和分步向导完成：

```text
描述需求 → 添加知识 → 选择入口 → 检查 → 发布 → 使用
```

## 已完成的产品底座

- Next.js Web、FastAPI、PostgreSQL、Redis 与 Docker Compose；
- Supabase 身份边界和租户模型；
- 机器人身份、草稿版本与 revision 冲突保护；
- 文字/网页资料登记、分段、来源和处理回执；
- 中英文路由与可替换模型/向量服务边界；
- 发布版本、运行记录和公开访客入口的工程结构。

## 当前诚实边界

本机产品底座可运行，但尚未部署公网实例；真实向量、回答供应商和第二外部用户验收仍未闭合。因此它展示的是产品架构与实现能力，不冒充成熟 SaaS。
