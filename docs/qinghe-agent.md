# 清禾 / Organic AI Agent

## 产品目标

让 AI 不只回答当前一句话，而是能在用户授权下结合长期信息和当前状态，调用工具完成真实任务，并清楚说明结果是否真正生效。

## 核心能力

- 长期记忆与来源追踪；
- 工具调用和多步骤任务；
- 权限、风险分级与操作确认；
- 任务状态、失败语义与结果回执；
- 个人知识库、生活记录、浏览器和电脑能力连接；
- 多渠道交互与上下文连续性。

## 我负责什么

- 定义产品目标与“什么算完成”；
- 设计模型判断与确定性系统之间的职责边界；
- 设计权限、任务、回执和记忆治理；
- 借助 AI 推进实现、调试、部署和故障复盘；
- 使用自然场景而非测试口令进行验收。

## 一个重要原则

模型负责理解、推理、取舍和表达；代码负责事实、权限、状态、幂等、副作用、验证与回执。不能用关键词路由和固定回复代替模型思考，也不能让模型猜测一个外部动作是否成功。

## 当前边界

核心工具和控制能力已持续运行，但部分跨渠道自然场景仍在继续验收；未取得最终用户回执的能力不会被描述为“已经完成”。
