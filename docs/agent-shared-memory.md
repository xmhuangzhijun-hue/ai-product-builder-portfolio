# Agent Shared Memory

## 问题

多个 AI 工具和新会话经常丢失项目上下文：不知道当前版本、重复已经失败的方案、把旧结论当成当前事实，或者只记住文字却没有改变后续行为。

## 设计

记忆按来源和用途分层：

1. 原始证据：保留来源和指纹；
2. 工程日志：记录行动、决策、失败和接续；
3. Agent 观察：只记录实际接触过的内容；
4. Shared：经过验证的当前共同认知；
5. 项目文件：实时规格、状态和代码，优先级最高。

## 关键机制

- 来源追踪与当前/历史区分；
- 候选记忆不能直接覆盖 shared；
- 失败经验必须在相似任务开始前被检索和复核；
- 状态、权限和动作回执由确定性系统管理；
- 用后续行为是否改变来判断“是否真的学会”。

## 价值

让 Codex、Claude Code、ChatGPT 与业务 Agent 能在不同窗口中连续协作，同时降低上下文丢失、重复踩坑和记忆污染。
